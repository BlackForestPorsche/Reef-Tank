# Guition / Sunton ESP32-S3-4848S040 pin map

Default firmware (`esp32-s3-panel`) drives this glass with Arduino_GFX + LVGL 8 + GT911. Pins below are copied from public 4848S040 sources — they were not invented. Edit `include/pins.h` on first flash if something is wrong; do not hunt through `main.cpp`.

## Board

| | |
|---|---|
| SoC | ESP32-S3-N16R8 (16 MB QIO flash, 8 MB OPI PSRAM) |
| LCD | 4.0" 480×480 IPS, ST7701, 16-bit RGB + 3-wire SPI init |
| Touch | GT911 on I²C |
| USB | USB-C, usually CH340 → UART0 (not native USB-CDC) |
| SKU | No-relay tank panel. Relay wall-box SKUs use GPIO 40 / 2 / 1 — leave those floating. |

## LCD

| Signal | GPIO | Notes |
|---|---|---|
| Backlight | **38** | Boost converter. HIGH = on. PWM dimming is flaky on this SKU. |
| ST7701 CS | 39 | 3-wire SWSPI, DC unused |
| ST7701 SCK | 48 | Shared with microSD clock |
| ST7701 MOSI | 47 | Shared with microSD MOSI |
| ST7701 RST | — | Tied internally. Use `-1` / `GFX_NOT_DEFINED`. |
| DE | 18 | |
| VSYNC | 17 | |
| HSYNC | 16 | |
| PCLK | 21 | 12 MHz typical. Tear / white: drop toward 12 MHz, try `st7701_type9`. |
| R0–R4 | 11, 12, 13, 14, **0** | **GPIO0 is also BOOT** |
| G0–G5 | 8, **20**, 3, 46, 9, 10 | GPIO20 is G1 |
| B0–B4 | 4, 5, 6, 7, 15 | |

Timing used by Arduino_GFX / openHASP for this panel:

- HSYNC polarity 1, FP 10, PW 8, BP 50
- VSYNC polarity 1, FP 10, PW 8, BP 20
- PCLK active-negative 0, prefer 12 MHz

## Touch (GT911)

| Signal | GPIO | Notes |
|---|---|---|
| SDA | **19** | |
| SCL | **45** | Strapping pin; community configs ignore the warning. |
| INT | — | Not routed on most modules. Poll. |
| RST | — | Not routed. |
| Address | `0x5D` | Alternate `0x14` if `begin()` fails. |

**19/20 vs 19/45:** some older Sunton listings say touch I²C is 19/20. Every RGB map above already uses **GPIO20 as G1**, so SCL cannot be 20. Arduino_GFX, ESPHome, and HomeDing’s working config all use **19/45**.

## Hold-to-pair (GPIO0)

The ESP32-S3 BOOT button is GPIO0. On this SKU GPIO0 is also TFT_R4. Firmware holds ~1.8s on GPIO0 to clear NVS and reboot into SoftAP. While RGB is running, that hold may glitch the red channel. That is expected. Glass long-press (~1.8s) also re-enters pairing without clearing NVS.

## Unused on the no-relay SKU

- Relays: GPIO 40, 2, 1
- microSD: CS 42, MISO 41, MOSI 47, SCK 48 (not used in 0.1.1-alpha)

## What the default firmware does

`esp32-s3-panel` is pairing SoftAP + LVGL glance for this SKU. `esp32-s3-panel-serial` skips glass libs if the jig only needs Serial. Dummy 4" UI stays at the Hub website `/panel` until a board is on the bench.
